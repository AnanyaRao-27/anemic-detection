# Anemic

A simple CNN-based project for anemia detection from eye images.

## Technologies
- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Tkinter

## Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python predict_anemia.py
```

## Files

- `prepare_data.py` – Checks and prepares the dataset.
- `predict_anemia.py` – Loads the trained model and predicts whether an eye image is **Anemic** or **Non-Anemic**.
